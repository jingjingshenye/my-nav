# 观澜 · 新标签页导航

> 名取《孟子》「观水有术，必观其澜」——万川归海，由此观澜。

参照 [inftab](https://inftab.com/) 风格实现的极简起始页：全屏壁纸、圆角搜索框（多引擎切换）、圆形图标网格、滚轮/方向键翻页。纯静态、零构建、零依赖。

核心特性：

- **文件夹组合（类桌面文件夹，对齐 iOS）**：编辑态点「新建文件夹」创建；拖 A 到 B 上**悬停片刻**即合成文件夹（合成后自动弹开并进入命名）；拖到已有文件夹上悬停片刻，文件夹自动弹开，松手移入（也可直接拖进浮层内部）；点文件夹从其图标位置 zoom 展开浮层，内部可打开/编辑/删除网址、＋ 添加新网址、点标题重命名；成员可拖到浮层外移出（成员移空的夹自动删除）；右键文件夹可重命名 / 解散（成员回到桌面）。
- **自由拖拽排序（SortableJS，对齐 iOS 主屏幕）**：拖拽常驻可用（无需编辑模式）；拖动时其余图标**实时让位**；悬停另一图标停顿 ≈0.45s 才升级为「合并/移入」意图（快速掠过只是排序，不会误建夹）；拖到屏幕左右边缘自动翻页、末页继续拖自动新建一页、拖到圆点区「＋」新建一页并放入；拖影只显示图标本体；删除/解散一律有确认。
- **自由增删改**：点右上角按钮弹出设置抽屉（添加 / 我的 / 设置三个 tab）；**右键任意图标进入图标编辑模式**（±2° 轻微旋转抖动，对齐 inftab；× 删除无确认框——缩放淡出动画即过渡；**仅悬停出现的铅笔按钮打开编辑面板**，点卡身无操作），编辑面板支持 网址 / 名称（目录命中或域名推导自动检测）/ 图标三选（纯色、按网址实时抓取的高清候选、本地上传）；右键文件夹出四项菜单（打开全部 / 重命名 / 解压 / 删除）；`E` 或「完成」退出。
- **搜索（对齐 inftab）**：搜索框上方 tab 为搜索类型 `网页 / 图片 / 新闻 / 视频 / 地图`（内部 id 与 inftab 一致：html/photos/news/videos/map）；引擎自带各类型地址模板，搜索词直接拼接在地址末尾（或替换 `%s`）。内置引擎库 7 个（bing、yahoo、yandex、duckduckgo、360搜索、sogou、yandex ru），默认仅启用 bing；点搜索框左侧 Logo 切换引擎，面板嵌在搜索框与图标之间，其中的「＋ 添加」可从引擎库启用或自定义引擎。输入网址直接跳转；输入关键字实时显示搜索建议（可关）。
- **设置面板（对齐 inftab，全部实时生效）**：目标打开方式（网站/搜索是否新标签打开）、视图（屏幕缩放、翻页按钮）、布局预设（自动/2x4~2x7/3x3/自定义行列）、图标（隐藏名称、阴影、启动动画+入场效果、圆角/不透明度/大小滑杆）、搜索框（隐藏、搜索建议、保留内容、隐藏类别、显示搜索按钮、大小/圆角/不透明度）、字体（阴影、大小、颜色色板含彩色）、壁纸（预设、自定义 URL、本地上传、遮罩/模糊滑杆）、重置设置（保留网址与云同步配置）。图标自动多源回退：站点 favicon.ico → DuckDuckGo → Google → favicon.im → 备用源，全部失败才显示字母头像。
- **壁纸库**：内置「必应每日壁纸」（多源自动回退：Peapix → 必应官方接口 → 直连）与「随机美图 Picsum」两个在线源，缩略图点选即应用；可勾选「每天自动更换为最新必应壁纸」。应用后的壁纸以 URL 形式写入配置，随 Gist 自动同步——Gist 只存文本，图片本身不占它的空间。
- **网站目录**：「添加」页内置 11 分类近 100 个常用网站，左侧竖排分类、搜索后一键添加；也可「＋ 自定义」添加任意网址。
- **数据云端同步（Gitee / GitHub Gist）**：导航数据存为一个私密 Gist 中的 JSON 文件，支持 Gitee 与 GitHub 两个平台（GitHub 需 Classic Token 并勾选 gist 权限），换电脑登录同一账号配置即可拉取；支持修改后自动同步、手动推送 / 拉取、导入导出 JSON、**本机历史备份节点**（保留最近 10 份快照，拉取云端 / 还原设置前自动备份，可随时恢复）。
- **接口自由**：存储层抽象为适配器接口（`js/adapters.js`），想换成自建 API、GitHub Gist、对象存储，写一个 `load/save` 实现并注册一行即可，界面下拉自动出现新选项。
- **Infinity 数据迁移**：`node migrate-infinity.mjs <导出的.infinity备份>` 可把 inftab/Infinity 的网址、图标、壁纸、布局与搜索引擎设置迁移到本项目；图标与壁纸下载到本地 `assets/`，转换结果写入 `data/default-data.json`，全新浏览器首次打开页面时自动加载。

## 本地运行

任意静态服务器指向本目录即可（直接双击 file:// 打开会因浏览器模块/CORS 限制无法请求云端）：

```bash
python -m http.server 8080
# 或
npx serve .
```

打开 <http://localhost:8080>。

领域逻辑（页面构成操作、数据规范化）抽在纯模块里，可直接跑单元测试（无需浏览器）：

```bash
node --test tests/
```

## 部署

### GitHub Pages（在线地址）

已配置 GitHub Actions 自动发布（`.github/workflows/publish-gh-pages.yml`）：推送到 `master` 分支后，站点文件（`index.html`、`css/`、`js/`、`data/`、`assets/`）会自动发布到 `gh-pages` 分支，由 GitHub Pages 服务在
<https://jingjingshenye.github.io/my-nav/>（约 1 分钟内生效）。

> 注：仓库的 `github-pages` 环境保护规则只允许默认分支部署，故采用 gh-pages 分支方式发布，而非 `actions/deploy-pages`。

### Gitee Pages

Gitee Pages 服务已停止，不再部署；Gitee 远程（`origin`）仍保留，用于代码备份与 Gist 云同步。

## 配置 Gitee Gist 云同步

1. 打开 <https://gitee.com/profile/personal_access_tokens>，「生成新令牌」，勾选 **gists** 权限（建议同时勾 user_info）。
2. 页面右上角菜单 →「数据同步」→ 同步方式选 **Gitee Gist（云端）**，粘贴 Token。
3. 点「推送到云端」：没有 Gist ID 时会自动创建一个私密 Gist（文件名默认 `nav-data.json`），并把 ID 写回配置。
4. 勾选「修改后自动同步」后，每次增删改会防抖 1.8s 自动推送；换设备时填同一 Token + Gist ID，「从云端拉取」即可。

说明：

- Token 只保存在本机浏览器 localStorage，通过 HTTPS 直连 Gitee，不经过任何第三方；上传云端的数据会自动剔除 Token 字段。
- 同步为"整包覆盖"，但拉取前有覆盖保护：本地有未推送修改且比云端新时会弹确认框（数据带 `updatedAt` 时间戳）。本地上传的图标/壁纸存在浏览器 IndexedDB，**不随云同步**——换设备后这些站点会回退为自动抓取图标。

## 自定义存储后端（接口自由）

`js/adapters.js` 中约定：任何适配器实现

```js
class MyAdapter {
  async load() {}          // 返回完整数据对象或 null
  async save(data) {}      // 保存完整数据对象
  async create(data) {}    // 可选：首次使用时创建云端存储，返回 id
}

ADAPTERS['my-backend'] = {
  label: '我的后端',
  create: cfg => new MyAdapter(cfg),
};
```

设置面板的「同步方式」下拉会自动出现「我的后端」。

## 搜索类型与引擎模型（对齐 inftab）

- **类型**（`TYPES`，`js/app.js`）：`html / photos / news / videos / map`，顶部 tab 直接切换。
- **引擎**（存于 `settings.engines`，随云端同步）：每条含名称和各类型地址模板，搜索词默认拼接在地址末尾；模板里写了 `%s` 则替换 `%s`。内置 7 个引擎的引擎库（`ENGINE_CATALOG`），默认仅启用 bing，其余可在「添加搜索引擎」对话框里一键启用，也可添加完全自定义的引擎。当前类型没配模板时回退到该引擎的 `html` 地址。
