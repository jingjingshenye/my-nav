# Nav · 新标签页导航

参照 [inftab](https://inftab.com/) 风格实现的极简起始页：全屏壁纸、圆角搜索框（多引擎切换）、圆形图标网格、滚轮/方向键翻页。纯静态、零构建、零依赖。

核心特性：

- **自由增删改**：点右上角按钮直接弹出设置抽屉，顶部快捷区可 添加网址 / 网站目录 / 数据同步 / 编辑模式 / 导入导出；右键任意图标可 编辑 / 删除 / 开关红点提醒；「编辑模式」下支持 iOS 风格抖动、点击修改、拖拽排序（可拖到翻页圆点上跨页移动）。
- **搜索（对齐 inftab）**：搜索框上方 tab 为搜索类型 `网页 / 图片 / 新闻 / 视频 / 地图`（内部 id 与 inftab 一致：html/photos/news/videos/map）；引擎自带各类型地址模板，搜索词直接拼接在地址末尾（或替换 `%s`）。内置引擎库 8 个（baidu、bing、yahoo、yandex、duckduckgo、360搜索、sogou、yandex ru），默认启用 baidu + bing；点搜索框左侧 Logo 切换引擎，面板嵌在搜索框与图标之间，其中的「＋ 添加」可从引擎库启用或自定义引擎。输入网址直接跳转；输入关键字实时显示搜索建议（可关）。
- **设置面板（对齐 inftab，全部实时生效）**：目标打开方式（网站/搜索是否新标签打开）、视图（屏幕缩放、右下角随机壁纸按钮、翻页按钮）、布局预设（自动/2x4~2x7/3x3/自定义行列）、图标（隐藏名称、阴影、启动动画+入场效果、圆角/不透明度/大小滑杆）、搜索框（隐藏、搜索建议、保留内容、隐藏类别、显示搜索按钮、大小/圆角/不透明度）、字体（阴影、大小、颜色色板含彩色）、壁纸（预设、自定义 URL、本地上传、遮罩/模糊滑杆）、重置设置（保留网址与云同步配置）。图标自动多源回退：站点 favicon.ico → DuckDuckGo → Google → favicon.im → 备用源，全部失败才显示字母头像。
- **壁纸库**：内置「必应每日壁纸」（多源自动回退：Peapix → 必应官方接口 → 直连）与「随机美图 Picsum」两个在线源，缩略图点选即应用；可勾选「每天自动更换为最新必应壁纸」。应用后的壁纸以 URL 形式写入配置，随 Gist 自动同步——Gist 只存文本，图片本身不占它的空间。
- **小组件与网站目录**：首屏前三位为待办事项 / 笔记 / 天气卡片——待办支持增删勾选且图标红点实时显示未完成数（对齐 inftab）、笔记自动保存、天气接入 Open-Meteo（免密钥，7 天预报+城市切换）；菜单「网站目录」内置 11 分类近 100 个常用网站，搜索后一键添加。
- **数据云端同步（Gitee Gist）**：导航数据存为一个私密 Gist 中的 JSON 文件，换电脑登录同一账号配置即可拉取；支持修改后自动同步、手动推送 / 拉取、导入导出 JSON、**本机历史备份节点**（保留最近 10 份快照，拉取云端 / 还原设置前自动备份，可随时恢复）。
- **接口自由**：存储层抽象为适配器接口（`js/adapters.js`），想换成自建 API、GitHub Gist、对象存储，写一个 `load/save` 实现并注册一行即可，界面下拉自动出现新选项。
- **Infinity 数据迁移**：`node migrate-infinity.mjs <导出的.infinity备份>` 可把 inftab/Infinity 的网址、图标、壁纸、布局与搜索引擎设置迁移到本项目；图标与壁纸下载到本地 `assets/`，转换结果写入 `data/default-data.json`，全新浏览器首次打开页面时自动加载。

## 本地运行

任意静态服务器指向本目录即可（直接双击 file:// 打开会因浏览器模块/CORS 限制无法请求云端）：

```bash
python -m http.server 8080
# 或
npx serve .
```

打开 <http://localhost:8080>。

## 部署到 Gitee Pages

仓库根目录即站点根目录，在 Gitee 仓库「服务 → Gitee Pages」中选择 `master` 分支根目录启动即可。

## 配置 Gitee Gist 云同步

1. 打开 <https://gitee.com/profile/personal_access_tokens>，「生成新令牌」，勾选 **gists** 权限（建议同时勾 user_info）。
2. 页面右上角菜单 →「数据同步」→ 同步方式选 **Gitee Gist（云端）**，粘贴 Token。
3. 点「推送到云端」：没有 Gist ID 时会自动创建一个私密 Gist（文件名默认 `nav-data.json`），并把 ID 写回配置。
4. 勾选「修改后自动同步」后，每次增删改会防抖 1.8s 自动推送；换设备时填同一 Token + Gist ID，「从云端拉取」即可。

说明：

- Token 只保存在本机浏览器 localStorage，通过 HTTPS 直连 Gitee，不经过任何第三方；上传云端的数据会自动剔除 Token 字段。
- 同步为"整包覆盖"（最后写入者胜出），暂无合并策略；重要变更可用「导出数据」留底。

## 自定义存储后端（接口自由）

`js/adapters.js` 中约定：任何适配器实现

```js
class MyAdapter {
  async load() {}          // 返回完整数据对象或 null
  async save(data) {}      // 保存完整数据对象
  async create(data) {}    // 可选：首次使用时创建云端存储，返回 id
}

ADAPTERS['my-backend'] = {
  label: '我的后端',
  create: cfg => new MyAdapter(cfg),
};
```

设置面板的「同步方式」下拉会自动出现「我的后端」。

## 搜索类型与引擎模型（对齐 inftab）

- **类型**（`TYPES`，`js/app.js`）：`html / photos / news / videos / map`，顶部 tab 直接切换。
- **引擎**（存于 `settings.engines`，随云端同步）：每条含名称和各类型地址模板，搜索词默认拼接在地址末尾；模板里写了 `%s` 则替换 `%s`。内置 8 个引擎的引擎库（`ENGINE_CATALOG`），默认启用 baidu + bing，其余可在「添加搜索引擎」对话框里一键启用，也可添加完全自定义的引擎。当前类型没配模板时回退到该引擎的 `html` 地址。
