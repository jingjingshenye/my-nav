# PRD · 图标网格管理交互规格（对齐 iOS 主屏幕）

> 版本 2.3 · 2026-09-25 · 本文档是图标管理交互的**唯一权威规格**。
> 范围：桌面图标网格 + 文件夹浮层网格的完整交互（含边界情况）。
> 不变项：数据模型（扁平 sites + parent + h 硬分页）、`js/domain/pages.js` 纯函数层。

---

## 1. 背景与决策

| 项 | 决策 | 原因 |
| --- | --- | --- |
| 拖拽库 | **移除 SortableJS，自研 Pointer Events 引擎**（`js/grid-manager.js`） | 列表排序模型与网格桌面冲突：实时让位挤跑目标、拖影不可控、缝隙语义无法表达。dnd-kit 偏 React、pragmatic-drag-and-drop 文档稀疏且同样不提供「停顿才挤开」 |
| 让位模型（v2.3 修订） | **实时重排（WYSIWYG）**：拖动中被拖卡真实换位（DOM 重排 + FLIP 过渡），洞随拖影；停顿 200ms 防快速掠过误排 | 用户定调修订：inftab 的即时生效让用户更早看到排列效果——不满意继续拖、满意松手即可，没有「松手后才发生」的意外；预览即结果（旧 transform 假象预览已废弃） |
| 排序 vs 合并 | 同一压住手势按**停顿时长**两阶段区分 | 短停（200ms）=挤开排序；长停（350ms）=回弹并升级为建夹/移入（时长与 inftab 逆向结果一致） |
| 压住判定 | **拖影中心 × 目标可见图标矩形**的双重中心重叠：判定点必须是拖影中心 `(px-offX+ghostW/2, py-offY+ghostH/2)`，判定域必须是目标的 `.icon` 矩形而非卡片单元 | 面积重叠比在密集网格恒 ≥50% 不可用（踩坑）；裸指针在抓边缘时超前半个图标宽（踩坑）；卡片单元（含标签/内边距）比图标大一圈，按卡判定时图标未重叠就升级合并=「边缘碰到就合并」（踩坑）。icon 在卡内偏移用 `icon.offsetLeft−el.offsetLeft` 同参照系差值求，避免 offsetParent 差异与 hover 缩放污染。图标之间空隙=缝隙排序领域 |
| 交互模型（v2.1 定稿） | **无自定义右键菜单**；右键图标=自动进入图标编辑模式；编辑模式只负责图标属性删改（× 删除、铅笔/点击编辑面板），不承担菜单管理、不直接弹属性抽屉 | 用户定调：菜单式右键与抖动编辑是两套心智，混用会互相干扰；编辑的进入应顺手（右键即进），属性抽屉须显式点击铅笔/图标才出现 |
| 不做 | 多选拖拽、iOS 18 任意摆放、键盘整理、页面/图标右键菜单 | 鼠标单指针无法诚实复刻双指堆叠；任意摆放与网格流布局冲突；菜单式右键与编辑模式职责重叠 |

## 2. 交互调研结论（iOS 主屏幕）

1. 拖动图标时其他图标**全程静止**；拖影悬停某格**短停**后该处图标让位（插入语义）。
2. 压住另一图标**长停**→ 目标放大白圈=建夹预览；压住文件夹 → 文件夹自动弹开可移入。
3. **拖成员离开文件夹 → 浮层立即缩回**（社区甚至抱怨它缩得太早），之后就是普通桌面拖拽。
4. 合成文件夹后**自动弹开并聚焦命名**；空夹自动删除；**只剩 1 个成员时夹自动解散、图标露出**。
5. 拖到屏幕左右边缘停顿翻页；末页继续向外拖自动新建一页。
6. 删除有确认；快速掠过目标不产生任何效果；长按系统默认 0.5s（Apple 手势文档）。
7. 参考实现：Kirupa 的 CSS jiggle 复刻、社区 SpringBoard clone（无单一权威文档，以上为多源交叉确认）。

| 项 | inftab 实测 | 观澜取舍 |

| 挂件 | 网格内混排天气等挂件 | 不做（范围外，远期） |

## 4. 拖拽状态机

```
IDLE ──pointerdown(主键，可拖卡，非按钮)──▶ PRESSED
PRESSED ──移动 ≥6px──▶ DRAGGING
PRESSED ──pointerup──▶ IDLE（放行 click）

DRAGGING（ghost 跟手；源卡半透明；body 禁选）：
  每帧（pointermove 驱动 + 停顿由定时器驱动）：
    ① onFrame 业务钩子（拖出缩回 / 弹开浮层的锁定判定，可接管本帧）
    ② 落点网格 = 指针所在网格（源网格优先；夹拖出后命中桌面全屏 hitArea）
    ③ 中心点压住某卡 → armed 放大预示：
         短停 200ms（目标非文件夹）→ 挤开让位（「洞随拖影」：原位与拖影之间的卡朝洞补一位，可随光标实时跟随）
         长停 350ms → 挤开回弹 + merge-target 白圈 → onPromote（业务定义意图）：
             普通x普通 → 「松手合并为文件夹」
             普通x文件夹 → 「松手移入」+ 文件夹自动弹开
             文件夹x文件夹 → 「松手合并文件夹」
             文件夹x普通 → 不升级（iOS 语义）
    ④ 未压住任何卡 → 缝隙模式：停留 200ms 挤开该缝隙
    ⑤ 屏幕左右 90px 停留 650ms → 翻页（末页右缘 → 新建一页，一次拖拽一次）
    ⑥ 拖出文件夹后：光标在桌面任意处都有效（hitArea 全屏）

pointerup → DROP（按优先级消费，互斥）：
  1. 夹并夹
  2. 移入文件夹（dropFolderId 存在即兑现——放弃语义已由离开浮层时清标记承担）
  3. 建夹 → 自动弹开浮层 + 聚焦命名
  4. 夹内缝隙 → reorderFolderMember
  5. 桌面缝隙/空页 → moveTopEntry（空页 hardBreak）
  6. 夹拖出到桌面 → 从原夹摘出 + 触发折叠检查 + 落位 + toast
  7. 无有效目标 → 原位回弹

Esc / pointercancel / blur → CANCEL（视觉全部回位，数据不动）
```

**参数**：`dragThreshold 6px · mergeDwellMs 350 · shiftMs 180 · edgePx 90 · edgeMs 650`。占位格即时跟随鼠标（无停顿门槛）；350ms 仅用于压住图标中心的合并/移入升级

## 5. 文件夹生命周期

| 事件 | 行为 |
| --- | --- |
| 建夹（拖 A 压 B 长停松手） | 合成 → 自动弹开浮层 → 聚焦命名 |
| 移入成员 | moveIntoFolder（硬分页随行转移） |
| 拖出成员（光标离开 fvGrid ±8px） | **浮层立即缩回** → 成员摘出（h 转移）→ 折叠检查 → 桌面落位 |
| 删除成员 / 拖出到剩 1 个 | **夹自动解散，最后的图标露出在桌面原夹位置**（三条路径统一触发） |
| 成员拖空 | 夹直接删除；浮层开着则收起 |
| 退出编辑模式 | 清理空夹 |
| 解散（右键/菜单） | confirm → 成员按原顺序补回夹位置 |

## 6. 视觉与层级规格

**视觉**：ghost=图标克隆，拿起过渡（scale 1→1.08、透明度 .55→1），跟手无惯性；源卡半透明驻留；压住预示 `hover-armed` scale1.06；升级 `merge-target` scale1.12+白圈+下方气泡；挤开 180ms ease、移开回弹；浮层从来源卡片 zoom 展开（transform-origin 动态）。

**几何铁律**：挤开预览的 transform 只作用于视觉；所有命中/中线/索引判定一律基于逻辑坐标（`offsetLeft/offsetTop`，不含 transform）。任何新判定若读 `getBoundingClientRect` 都会被预览平移污染，造成目标振荡与落点偏移。

**z-index 层级表**（右键菜单必须压过一切浮层）：

| 元素 | z-index |
| --- | --- |
| 拖拽 ghost | 999 |
| 图标筛选遮罩 / 编辑面板 | 86 / 85 |
| 完成浮条 / 抽屉 / 抽屉遮罩 | 80 / 80 / 79 |
| 文件夹浮层 / 遮罩 | 70 / 69 |
| 翻页圆点 | 30 |

**触屏**：卡片 `touch-action:none`（按住即拖）、`-webkit-touch-callout:none`（长按不呼出系统菜单）、图标 `pointer-events:none`（不拦截命中与拖影）。

**原生拖动禁用（关键）**：卡片是 `<a href>`，浏览器会把「按住拖动」解释为拖链接——触发 pointercancel 抢走指针，表现为**不进编辑模式就拖不动**（编辑态卡片无 href 所以能拖，极具迷惑性）。三重防护：卡片 `draggable=false` + CSS `-webkit-user-drag:none` + 引擎 `dragstart` capture `preventDefault`。拖拽因此与编辑状态**完全解耦**：任何状态下按住即拖。

## 7. 架构（grid-manager.js）

```
app.js（业务）──语义回调──▶ grid-manager（引擎，零业务依赖）──▶ domain/pages.js（数据纯函数）
```

- 引擎职责：指针会话、ghost、压住判定（点判定+迟滞）、两阶段停顿（定时器驱动，鼠标停住不动也触发）、缝隙挤开（rect 差分，适配换行）、边缘翻页计时。**引擎永不改业务 DOM 顺序**，落位由业务在 onDrop 调 domain 函数。
- `registerGrid(spec)`：`{ id, pageEl(), hitArea?(), canDrag, entryOf, fromCtx?, sortableOnly?, edgeFlip?, onDragStart, onFrame(可接管帧), onTarget, onPromote, onGapSettle, onEdgeFlip, onDrop, onCancel }`
- 两实例：`desktop`（edgeFlip + hitArea 全屏 + onPromote 建夹/移入/弹开）与 `folder`（sortableOnly + 重排/拖出）。
- 回调派发规则：onPromote/onTarget 按**落点网格**优先（拖出成员压住桌面目标时由桌面语义响应）；onDrop 恒为**源网格**（业务按 from 分派）。

## 8. 边界情况与已知限制

**已定义行为**：拖到自己原位=无操作；拖出后再压回原夹图标=移回；放弃移入=拖离浮层（清标记）；拖拽中 Esc/失焦=取消；浏览器缩放按 CSS 像素计算，天然兼容。

**已知限制（明确暂不做）**：
1. 拖拽中窗口 resize：网格重建后源卡视觉暂丢、拖拽继续但落点以新布局为准。
2. 多浏览器标签页同时操作：storage 无跨标签同步，后保存者覆盖。
3. 文件夹成员超过一屏：浮层内滚动，无拖拽到边缘自动滚动。
4. 触屏长按无系统 haptic 震动反馈（Web 无接口）。
5. 键盘整理图标（无障碍方向键移动）暂无需求。

## 9. 测试计划

**domain（node --test，29 用例）**：硬分页转移、建夹/解散/合并/重排、折叠（剩 1 解散）、sanitize。

**e2e（页面内毫秒级手势编排，含真实停顿）**：
1. 按下启动：ghost 出现、源卡半透明、**其他图标零位移**
2. 压住短停（~260ms）：目标位置起顺延挤开；未到 200ms 不挤开
3. 挤开后松手：落位正确（含插入末尾无挤开特例）
4. 长停（>350ms）：回弹+白圈+聚光压暗；松手建夹+自动弹开+命名聚焦
5. 快速掠过：无效果
6. 压住文件夹长停：弹开+移入；badge 刷新
7. 夹内重排；夹内拖出：浮层立即缩回→桌面落点→移出→剩 1 解散
8. 拖出后压住桌面图标长停：从原夹摘出并建夹
9. 编辑态拖图标进文件夹：移入成功（回归重点）
10. 删成员到剩 1：夹解散、图标露出、浮层收起
11. 拖到屏幕边缘：翻页/新建页
12. Esc 中断：全部回位、数据不变
13. 编辑态进入/退出、删除确认、右键菜单三语言

## 11. v3.0 时代：inftab 原版模型完整移植（2026-09-29/30）

> v2.x 的 SortableJS/自研几何判定模型整体废弃，拖拽引擎重写为 `js/grid-manager.js`。
> 以下为现行权威规格（代码注释为最细粒度文档）。

### 11.1 架构（inftab 逆向结论的移植）

| 层 | inftab 原版 | 观澜实现 |
| --- | --- | --- |
| 命中 | DOM 落点元素（图标 data-dropid / 页尾 end / 边缘 aside） | 同：elementFromPoint → closest('[data-dropid]') |
| 调度门 | `_scheduler` 的 (area, dropId) 配对变更门 | 同：配对不变零计算（防闪烁的根本） |
| 落库 | 停顿即真实数据操作（sortSites/createFolder/intoFolder） | 同：缝隙 200ms → onSort；center 350ms → onCenter；弹窗同帧 |
| 分区 | _calcArea：指针定侧向、ghost 中心定 center（图标 20%~80% 横带） | 同 + center 迟滞（已 center 态用宽带保持） |
| 防抖 | 让位动画自然间隙 | + FLIP 冻结窗 230ms（动画中目标移动不重算）+ 冻结到期补发 |

### 11.2 分页（finishingSites / reSort 双语义）

- 日常变更：rebalancePages——溢出级联（满页尾挤下页头）、空页删除、**删不回填**（页内空洞保留）、h 页首标记持久化
- 布局（行列/预设）变更：repageAll——摊平按新容量纯密度重切（页构成重置）
- 新增：addTopLevelSite 从当前页向后找空位 + 跳落位页（submitSite 语义）
- 边缘：aside 窥视循环（白罩淡入 300ms → 翻页 → 淡出 600ms → 驻留循环），宽度 min(10vw,130px) 钳制网格余量

### 11.3 文件夹全流程

建夹 350ms → 同帧弹窗（zoom 自夹卡 + 拖影缩 0.8 + 面板内被拖项隐形占格）→ 拖出双段定时器（dragOutFolder 逐句：原点持久 + 首窗必然零位移无害）→ 落点/松手才移出。右键四项：打开全部(N)/重命名/解压/删除。常驻改名输入框（80 上限）。

### 11.4 编辑模式

±2° 旋转抖动（inftab spin，文件夹不抖）；仅悬停铅笔打开编辑（点卡身无操作）；× 删除无确认（缩放淡出 300ms 即过渡）；卡片跨编辑态复用（切编辑零闪烁）。

### 11.5 图标质量链

高清源瀑布（apple-touch/precomposed/android-chrome-512/icon-512/favicon.svg → favicon.im?larger&throw-error-on-404 → unavatar → ddg → faviconkit → clearbit → google → favicon.ico 沉底）+ 尺寸守门（<40px 降级）+ 会话级死源黑名单 + 放大倍率判据（naturalWidth < 显示宽×0.8）的色板徽章（host 哈希哑色系）+ USM 锐化（SVG feConvolve，A/B 截图验证）。favicon.im CORS 本网络被挡——Canvas 取色不可行（实测结论）。

### 11.6 已知未做（范围外）

云同步多端合并（现为 updatedAt 水位 + 覆盖确认）、天气挂件、AI 超分（效果差不引入）、矢量描摹（以 favicon.svg 直探替代）。
